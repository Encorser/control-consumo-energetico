# Evidencias de referencia: Actividad 6 anterior

## Propósito

Se cuenta con un paquete de capturas de una actividad previa de práctica básica de GitHub. Se aprovechará únicamente como **material complementario de referencia** para mostrar ejemplos de organización y documentación de un repositorio.

## Material disponible

También se preparó un anexo visual de nueve páginas (portada y ocho capturas) llamado anexo_evidencias_referencia_actividad6.pdf. Ambos artefactos están disponibles en la conversación para descarga; todavía no se han subido como binarios a GitHub. El archivo original github-recovery-codes.txt se excluyó por seguridad.

## Limitación importante

Las capturas corresponden a la actividad previa y muestran elementos de ese trabajo, no necesariamente el repositorio control-consumo-energetico. Por ello:

- Se pueden mencionar como **ejemplos complementarios de una práctica anterior**.
- No se deben etiquetar como capturas del proyecto energético actual.
- No sustituyen las capturas del repositorio actual, sus diagramas, el PowerPoint incorporado y su historial de commits.
- No se incluirán contraseñas, tokens ni códigos de recuperación en el repositorio ni en el documento final.
