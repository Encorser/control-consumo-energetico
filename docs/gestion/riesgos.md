# Gestión de riesgos

Proyecto: **Control de consumo energético enfocado a una casa habitación**

Se identificaron tres riesgos principales para el desarrollo y uso del sistema. Las probabilidades e impactos se presentan de forma cualitativa como una valoración inicial del proyecto hipotético, no como resultados de mediciones reales.

| ID | Riesgo | Probabilidad | Impacto | Medida preventiva o respuesta |
|---|---|---|---|---|
| R01 | Captura incorrecta de los datos de un recibo de CFE. | Media | Alto | Validar que las fechas, el consumo en kWh y el importe estén completos y tengan formato válido. Mostrar un mensaje si falta un dato o se detecta un valor inválido. |
| R02 | Falta de recibos anteriores suficientes para comparar periodos. | Media | Medio | Informar al usuario cuando no exista un periodo anterior disponible y evitar generar comparaciones o recomendaciones basadas en datos insuficientes. |
| R03 | Retrasos en la elaboración de la documentación y las evidencias del proyecto. | Media | Alto | Dar seguimiento a las tareas mediante GitHub Projects, priorizar las actividades pendientes y guardar avances parciales en el repositorio. |

## Seguimiento

Los riesgos se revisarán durante el avance del proyecto. Si cambia el alcance o se identifica una situación nueva, se actualizará la documentación y se registrará el cambio en el repositorio.

**Nota:** las probabilidades e impactos son estimaciones iniciales para la planificación académica y podrán ajustarse conforme avance el proyecto.
